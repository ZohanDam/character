# Changelog

## 1.0.0

- Twelve character traits, including Endurance, in an automatic Sunday–Saturday rotation.
- Editable trait names and definitions.
- Any number of distinct daily reminder times; default schedule 8:00 AM.
- System, light, and dark appearance.
- App description and installed version in About Character.
- On-demand GitHub update checks and direct release APK downloads.
- Local storage and a small native Android interface.
